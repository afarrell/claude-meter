The single gold Fable cell is gone. The statusline now shows a 7-day Fable sparkline beside the overall one, from per-day Fable history recorded in `~/.cache/claude-usage-history.json` (cycle `scoped` array), coloured like the overall sparkline and purple only when ahead of pace. It wraps onto a second, day-aligned line when `COLUMNS` minus `CLAUDE_METER_RESERVE` is too narrow; the dotfiles statusline wrapper sets the reserve. The companion Stream Deck plugin (`~/Projects/claude-usage-sd-plugin`, a local-only repo) pages per key through weekly bars, a daily overlay and a 5-hour view, flashes a 5-hour burn alert, and logs timing for page switches.

## Key Decisions

- Statusline layout: Fable side by side with the overall sparkline; a second row only on narrow terminals. A true overlay can't be drawn in a single terminal cell.
- Week boundaries come from Anthropic's real `resets_at` and the tracked cycle, not a fixed day (currently Wednesday 08:59 CEST).
- Stream Deck: one key cycles three pages, each key remembers its own page, and a press during a 5-hour alert acknowledges it instead of paging.
- Claude Mods: keep this Rust core as the source of truth and add a mod front end for the real overall/Fable overlay chart; don't rewrite claude-meter as a mod.
